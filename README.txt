HOW TO VIEW THE WEBSITE
1. Extract the .zip file.
2. Open index.html in Chrome, Safari, or Edge.
3. Click the top links to open About, Skills, and Education.
4. Click Let's Talk to open the working contact panel.
5. Use Send an Email (opens the email application), Call Me (opens phone dialer on supported devices), Copy, or Download Resume.

HOW TO PUT IT ONLINE FOR FREE (GITHUB PAGES)
1. Create a GitHub account and new PUBLIC repository named e.g. stepphanie-portfolio.
2. Upload ALL files and folders from inside this portfolio folder to the repository ROOT.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
4. Select the main branch and / (root), then Save.
5. After GitHub publishes, the link generally looks like:
   https://YOUR-GITHUB-USERNAME.github.io/stepphanie-portfolio/

IMPORTANT
- The Projects section was deliberately omitted.
- The listed technical stack includes Java, HTML and CSS only.
- The phone/email links are real functional links, but actual email sending requires an email app.
- Contact drawer does not send or collect form data on any server.
- The resume contains only the details visible in the screenshots; verify before applying.
- The user's street address and birth date were intentionally excluded from this publicly shareable portfolio.
- Google Fonts load when online; the website uses local fallback fonts without internet.
